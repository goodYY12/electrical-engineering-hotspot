# Report template

1. Target identity, cutoff date, scope, and program ID
2. Official facts: policy and five-cycle evidence table
3. Calculated results: quota derivations and admitted-score distributions
4. Subject profile and change timeline
5. Retest and transfer rules
6. Research directions/platforms and employment evidence
7. Community observations, separated into organic/commercial and verification status
8. Eight-dimensional risk portrait
9. User fit, migration cost, historical preparation target bands, and position
10. Uncertainty, conflicts, data-quality issues, and reassessment triggers
11. Core sources and Evidence IDs

Within each section label content as `【官方事实】`, `【计算结果】`, `【社区观察】`, `【分析判断】`, or `【不确定项】`. Every key number cites an Evidence ID.
